A+ rehearsal checklist

Three memory beats only: Friday→Monday · the cut · one Monday move. If the cut doesn’t land, the talk caps at B−.

  • Memorize the 60-second open (below)
  • Run the Cursor path 3×; write the exact reject line you will say
  • Time slides 2–9 once with a stopwatch (target ~12 min); slides 5 ≤ 75s, 6 ≤ 45s
  • Auto-build slides (PowerPoint): 4, 5, 6, 8, 10 — beats fade in automatically (After Previous); your click / → goes to the next slide. Speak over the cascade; don’t wait for each click
  • Practice Zoom share switch: deck → Cursor → deck
  • At slide 11, pause for the one-action commit before chat paste / Q&A
  • Say the craft line hard three times max: open · after the cut · close — don’t dilute it mid-talk
  • If something feels thin, cut words from slides 5–6 — do not add slides

Success test: Three beats in under 20 seconds · cut on camera without apology · slide 11 forces a choice · 5–6 under ~2 min combined. Rehearse builds once so Space doesn’t accidentally skip past a reveal.

  • On slide 9, use the mouse as a pointer; don’t scroll or click around

If someone asks…

Why not just ADO?
ADO = execution. ATLAS = commitments, health, narrative for leadership. Different job.
Did AI build the whole thing?
AI helped us build faster in Cursor. Structure, governance, what leadership sees — deliberate product design.
Can we get ATLAS / is it for sale?
It’s our internal instrument. Steal the pattern: pain → written spec → build with review → trust the numbers.
Do I need to be a developer?
No. Start with Copilot. Cursor when off-the-shelf doesn’t fit — still start with a written spec.
Cursor vs Claude Code?
Similar goal — project-wide AI assistance. Cursor = visual editor; Claude Code = terminal agent. Same rule either way.

What to say

3 · Ask — first prompt (3:00–6:00)

Paste or type slowly enough that people can read:

Read these files. I am presenting to PMI project managers. What is the through-line? Propose a 5-part story arc. Outline only — no slides yet.

Narrate while it runs (fill silence)

“I asked for an outline, not a finished deck — so I stay in control of the story.”

“I’m watching for: wrong claims, jargon I wouldn’t say, fluff leadership doesn’t need.”

When output appears: scroll once, highlight with the cursor, stay quiet 2–3 seconds so they can read.

4 · Climax — cut what’s wrong (6:00–9:00) — MUST LAND

Non-negotiable: Find one wrong, fluffy, or overconfident line. Delete it on screen. Say your scripted reject out loud — pick one and stick to it:

  • “That’s not true.”
  • “That’s not how we talk.”
  • “Leadership doesn’t need this.”

After the cut — land the thesis

“That cut is the whole point. Same discipline that kept ATLAS trustworthy — I don’t ship what I can’t stand behind.”

“Keep going until I’d put my name on it.”

Do not skip this for a prettier generate-only demo.

5 · Build — one artifact (9:00–12:30)

Pick one (don’t do all three live):

  • A: Meeting notes → action table HTML (most PM-friendly)
  • B: Draft speaker notes — spoken, not corporate — then cut again
  • C: Status email draft from bullets (fast if time is short)

From meeting-notes.txt, create HTML table: Action | Owner | Due | Status. Flag ambiguities at top for me to resolve.

While it builds

“Notice I asked it to flag what it’s unsure about — that’s judgment staying with me.”

Quick second cut if something is off — shorter than the climax cut.

6 · Wrap (12:30–15:00)

“Recap: sources → draft → cut what’s wrong → own it → share.”

“If you’re starting out: Copilot, meeting notes → action table — same discipline, smaller step. Cursor when nothing off-the-shelf fits — start with a written spec, like we did for ATLAS.”

“I’m switching back to the deck — pick one thing for this week.”

Voice tips while Cursor is thinking

  • Never go silent >8 seconds — narrate what you’re looking for
  • Prefer “I’m checking…” over “wow, look how fast”
  • If output is good: still find something small to tighten — shows standards, not magic
  • If output is bad: smile and cut — that’s the demo working

If something breaks

  • Open saved output immediately and do the same cut out loud — no apology tour
  • “Even the demo needs a PM — that cut is the craft.”
  • Share fail: stop Cursor share → re-share window → continue from saved file
